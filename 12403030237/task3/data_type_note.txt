选择 Hash：因为个人信息包含多个字段（学号、姓名、班级等），Hash 能将多个键值对集中存储在一个键下，便于单独修改或读取某个字段，且比创建多个独立 String 键更节省内存。

选择 Set：因为已完成的章节记录具有唯一性（不能重复记录），Set 的天然去重特性完美契合，且方便后续进行求交集或判断某章节是否存在等操作。

选择 Sorted Set：因为排行榜需要根据分数进行自动排序，Sorted Set 在插入数据时就会自动按分数排好序，查询前 N 名或个人排名的时间复杂度极低（O(log N)），非常高效。

选择 String：因为会话标识通常只是一个简单的字符串，配合 SETEX 指令，可以在同一个原子操作中完成赋值并设置过期时间（5秒），是实现带过期时间缓存最简单直接的方式。
